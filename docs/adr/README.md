# Architecture Decision Records

This directory contains Nabe's canonical architecture and security decisions.

Older topic docs in `docs/*.md` remain useful background material, but when a
topic is covered by an accepted ADR, the ADR is authoritative. If a later ADR
changes a decision, the later ADR must mark the previous record as superseded.

## Status Values

- `Accepted`: active decision.
- `Superseded`: replaced by a newer ADR.
- `Proposed`: under discussion and not yet binding.
